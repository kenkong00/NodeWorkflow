# 节点编辑工作流 v0.1

**ComfyUI 同款节点编辑工作流系统** —— 通过对 ComfyUI v0.9.2 的完整逆向，1:1 复刻其节点连接方式、交互规则、执行引擎与插件机制。

## 快速开始

```bat
start.bat            :: 生产模式：自动构建 + 启动预览服务 + 打开浏览器（推荐）
start-dev.bat        :: 开发模式：vite dev（改代码热更新，仅开发时用）
```

启动后自动打开浏览器访问 **http://localhost:5173**（首次启动会先构建约 10 秒）

> **为什么默认生产模式？** dev 服务器一旦重启，已打开的页面会进入 disconnected 状态、
> 所有操作静默失效。生产模式是静态文件 + 稳定服务，不会出现这种假死。

### 基本操作（与 ComfyUI 一致）

- **右键点击画布空白处** → 弹出搜索框，输入即过滤，↑↓ 选择，Enter 添加
- **右键点击节点** → 节点菜单：重命名 / 节点颜色（9 色板）/ 忽略此节点 / 折叠 / 克隆 / 删除
- **双击节点标题** → 直接进入重命名
- **从输出端口拖到空白处松手** → 自动弹搜索框，只列可连接的节点，选中后自动连线
- **拖线悬停在节点上** → 每个类型兼容的控件左侧浮现隐藏输入端口，松手即连；连上后该控件置灰、值来自上游
- 双击画布空白处 → 同样弹出搜索框
- 左侧「节点库」拖拽节点到画布，或点击添加（落点即鼠标松开的位置）
- 拖动端口连线（输入端口单连线，自动替换旧线；Ctrl+Alt+点击断开）
- 空白处拖动平移 / 滚轮缩放 / Ctrl+拖动框选
- **拖节点右下角**（26px 命中区内）缩放节点；图片类控件跟着等比拉伸，拉大无上限、缩小有下限
- Ctrl+Enter 运行 / Ctrl+S 保存
- 顶栏标签**双击重命名**；未保存过的工作流点保存会进「另存为」对话框

### 节点属性（视觉区分与流程控制）

| 功能 | 说明 |
|---|---|
| 节点颜色 | 右键节点 → 9 个固定颜色，只染标题栏，保持主体深色；可一键恢复默认；随工作流保存 |
| 忽略节点 | 右键 → 忽略此节点。橙色虚线框 + 「已忽略」角标，控件全部置灰；运行时**跳过该节点，把上游同类型值直接透传给下游**（ComfyUI 的 bypass 语义，不是断链） |
| 折叠 / 克隆 / 删除 | 右键菜单，`Delete` 键直接删 |
| 图片控件 | 无黑底、等比 `contain`、贴满节点宽度，节点拉高图片跟着变高 |


### 打开工作流（四种方式）

1. **左侧竖条「打开」→「示例工作流 ④ 三链合一」** —— 一键加载可运行的三条链（推荐首次体验）
2. **拖拽 `.json` 工作流文件到画布** —— 直接打开（ComfyUI 同款）
3. 左侧竖条「打开」→「从本地文件打开（.json）」
4. 左侧竖条「打开」→ 列表中选择已保存的工作流

### 图片输入（两种方式）

- **拖拽图片文件到 LoadImage 类节点上** → 上传并自动填入该节点
- 拖拽图片到画布空白处 → 自动创建 LoadImage 节点并填入
- 也可以点节点上的上传图标选择文件；节点上直接显示缩略图，预览节点显示「宽×高 · 文件名」

### 界面（左侧竖条 + 多标签，ComfyUI 同款）

| 位置 | 内容 |
|---|---|
| 顶栏 | logo + 工作流多标签（未保存显示圆点、可关闭、可新建） + 运行/停止 |
| 运行按钮 | 纯图标，运行中四周呼吸；右上角数字 = 运行中 + 排队中的任务数，可连点多次提交 |
| 停止按钮 | 只有 1 个任务时点击直接停；多个任务时展开「任务队列」下拉，逐条取消或全部停止 |
| 左侧竖条 | 新建 / 打开 / 保存 / 另存为 ‖ 节点库 / 适应视图 ‖ 插件 / 设置 / GitHub（悬停显示名称） |
| 底栏 | 执行状态、当前节点、错误信息、「本机执行引擎」标识 |

> 全系统不使用 emoji，所有按钮都是统一线性 SVG 图标 + 中文悬停提示。

### 插件

「插件」对话框安装 GitHub 插件（ComfyUI-Manager 同款体验），对话框内有使用说明。

## 核心特性

- **434 个 ComfyUI 基础节点全量照搬**（schema 级复刻，真机导出），**457 个节点全部可构造**（0 个空白节点）
- **同款连接规则**：`*` 通配、多类型逗号排列、EVENT↔ACTION、禁止自连
- **同款胶囊组件行**：一行 = `名称 …… 值 ◀ ▶`，值直接写在胶囊里、左右内边距固定 → 天然对齐；有组件的输入**不再单独占端口行**
- **同款组件隐藏端口**：鼠标划过组件行左侧浮现输入端口（已连线的常显实心点），按住即可拖出连线；从上游输出拖到组件行上也能直接接
- **同款节点右键菜单**：重命名 / 颜色 / 忽略（bypass）/ 折叠 / 克隆 / 删除
- **组（Group）**：蓝色半透明框包住一群节点，可整组拖动、统一忽略（bypass）、统一打标颜色、解散
- **真多选**：Ctrl 点选后一起拖动不散；多选状态右键仍保留选区，可一次删除整组节点
- **只显示本机可运行节点**：节点库顶部开关（默认勾选，localStorage 记忆）**同时作用于画布右键的「搜索节点」**，搜不到的本机节点不会列出
- **同款执行引擎**：validate_prompt → ExecutionList 拓扑调度 → 环检测
- **同款 API**：`/object_info` `/prompt` `/queue` `/queue/cancel` `/interrupt` `/history` `/view` `/ws`
- **原生节点本地执行**（文本/数学/图像/LLM），扩散类节点自动委托真实 ComfyUI
- **插件系统**：`plugins/` 目录即 `custom_nodes/`，支持 `NODE_CLASS_MAPPINGS` + `WEB_DIRECTORY`
- **官方 Dark 调色板**：端口按类型着色，与 ComfyUI 视觉一致

## 验收脚本（真机，CDP 真实鼠标键盘）

```bat
node .tools\probe-nodes3.mjs   :: 457 个节点全量构造冒烟
node .tools\accept4.mjs        :: 界面 30 项（缩放、运行、保存、设置、插件）
node .tools\accept5.mjs        :: 多任务 20 项（角标、呼吸、任务下拉、逐个取消、全部停止）
node .tools\accept6.mjs        :: 交互相 40 项（网格/拖入/对齐/右键菜单/忽略/图片弹性/缩放手柄/隐藏端口/服务商/另存为）
node .tools\accept7.mjs        :: 版面 26 项（组面板/组菜单/组内忽略/Ctrl 多选拖动/右键保留选区/批量删除/组件即端口/端口浮现拖线）
node .tools\accept8.mjs        :: 过滤 16 项（默认只显示本机可运行节点、节点库与右键搜索共享开关、持久化）
node .tools\probe-outcol.mjs   :: 输出列 8 项（不压输出名 / 折叠节点 DOM 一起收起 / 展开复原）
node .tools\probe-outcol-all.mjs :: 全量 457 节点压到最小宽度查「压输出名」→ 0 个
node .tools\queue-test2.mjs    :: 后端队列语义 10 项（cancel / interrupt / 中断后可继续跑）
```

> 验收脚本需要先起服务（`start.bat` 默认 5173），全部走 CDP 真实鼠标键盘事件，
> 不用 `element.click()`（那会绕过命中测试造成假通过）。

## 注意事项

- **请使用 `start.bat` 启动**（内置 Node 22 运行时）。系统 Node 24 会因 better-sqlite3 ABI 不匹配导致数据库初始化失败。
- 首次启动会自动 `npm install`。
