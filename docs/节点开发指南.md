# 节点编辑工作流 v0.1 · 节点开发指南

新系统的节点是 **schema 驱动**的：后端注册一份 `/object_info` 兼容的 `NodeDef`，前端 `nodeFactory` 会自动把它编译成带端口、控件、着色的 LiteGraph 节点类；执行由后端的 `NativeNodeImpl` 完成。

## 1. 节点 Schema（与 ComfyUI V1 完全一致）

```ts
{
  input: {
    required: {
      // 输入名: [类型, 配置]
      text: ['STRING', { multiline: true, default: '' }],
      op:   [['add', 'sub', 'mul'], { default: 'add' }],   // 数组 = COMBO
      seed: ['INT', { default: 0, min: 0, max: 1e15, control_after_generate: true }],
      image: ['IMAGEUPLOAD', {}],                          // 上传控件
      flag:  ['BOOLEAN', { default: true }],
    },
    optional: {
      api_config: ['API_CONFIG', {}],                      // 纯端口输入（无控件）
    }
  },
  output: ['STRING'],            // 返回类型列表
  output_name: ['TEXT'],         // 端口显示名
  name: 'MyNode',                // class_type（唯一标识）
  display_name: '我的节点',
  description: '节点说明',
  category: 'utils/text',        // 侧栏分类（支持 a/b 多级）
  output_node: false             // true = 输出节点（工作流必须至少一个）
}
```

### 类型 → 控件映射（nodeFactory 自动）

| 类型 | 控件 |
|---|---|
| INT | 数字框；带 `control_after_generate` 变 seed 三态（固定/+1/随机） |
| FLOAT | 数字框；`display:"slider"` + step/min/max 变滑块 |
| STRING | 单行输入；`multiline:true` 变多行文本 |
| BOOLEAN | 开关 |
| COMBO（数组类型） | 下拉框 |
| COLOR | 取色器 |
| IMAGEUPLOAD | 上传按钮（POST /upload/image） |
| 其他（MODEL/CLIP/LATENT…） | 纯端口，无控件 |

### 端口配色

`src/engine/litegraphSetup.ts` 的 `SLOT_COLORS` 按类型着色（ComfyUI 官方色值）：CLIP #FFD500、IMAGE #64B5F6、LATENT #FF9CF9、MODEL #B39DDB、VAE #FF6E6E 等。

## 2. 添加一个原生节点（三步）

以「字符串大写」节点为例：

**① `server/nativeNodes/myNodes.ts`**

```ts
import type { NativeNodeImpl } from '../registry/types'

export const upperCaseImpl: NativeNodeImpl = {
  execute: (ctx) => ({ result: [String(ctx.inputs.text ?? '').toUpperCase()] })
}

export const nativeMyDefs = [
  {
    name: 'UpperCase',
    def: {
      input: { required: { text: ['STRING', { default: '' }] } },
      output: ['STRING'],
      output_name: ['TEXT'],
      name: 'UpperCase',
      display_name: '大写转换',
      description: '把输入文本转为大写。',
      python_module: 'native.my',
      category: 'utils/text',
      output_node: false
    }
  }
]
```

**② `server/nativeNodes/index.ts`** 注册：

```ts
import { nativeMyDefs, upperCaseImpl } from './myNodes'

const IMPLS = { /* ... */ UpperCase: () => upperCaseImpl }
const DEFS = [ /* ... */ ...nativeMyDefs ]
```

**③ 完成。** 刷新页面后：
- 「节点库」侧栏 `utils/text` 分类出现「大写转换」
- 双击画布搜索 "大写" 可添加
- 连线、执行、保存全部自动可用

### 执行上下文

```ts
interface ExecContext {
  inputs: Record<string, unknown>   // 连线值优先，否则控件字面量
  nodeId: string
  isCancelled: () => boolean        // 长任务轮询
  onProgress: (ratio: number) => void
}
// 返回：{ result: unknown[] }  // 对应 output 列表；可选 ui: unknown 给输出节点显示
```

图像节点返回 `{filename, subfolder, type}` 引用对象（ComfyUI 惯例），预览经 `/view` 读取。

## 3. 无原生实现的节点

不注册 impl 即可——该节点会保留在 `/object_info`（照搬的 434 个基础节点全部如此），执行时**自动委托**给真实 ComfyUI（见 `plugins/comfy-executor`）。适用于 MODEL/LATENT/采样器等扩散链路。

## 4. 自定义控件

`src/engine/widgets.ts` 提供 11 种 DOM 控件工厂（number/slider/text/combo/toggle/color/upload/seed/image-preview/text-display/chat），新类型在 `nodeFactory` 的 `WIDGET_TYPES` 集合加一行即可接入。控件通过覆写 `LGraphCanvas.drawNodeWidgets` + `ctx.getTransform()` 定位到节点上（ComfyUI 同款机制），无需改引擎。

## 5. 输出节点

`output_node: true` 的节点执行完成后：
- 名称含 Image/图像 → 自动挂图像预览控件
- 名称含 Text/文本 → 自动挂文本显示控件
- `ChatNode` → 挂聊天控件

显示数据来自 impl 返回的 `ui` 字段（`{ images: [...] }` / `{ text: [...] }` / `{ chat: [...] }`）。
