# 样式库优化方案

## 问题分析

1. **保存按钮禁用问题**：当前所有内置样式（`isSystem=true`）的保存按钮都是禁用的，用户无法修改内置样式
2. **编辑器不够友好**：只有 JSON 文本编辑，小白用户难以上手，需要可视化表单编辑器

## 优化方案

### 1. 解决保存按钮问题
- 添加"复制为自定义样式"功能，让用户可以复制内置样式后再修改
- 保留 JSON 编辑作为高级选项
- 对于自定义样式，保存按钮正常可用

### 2. 添加可视化表单编辑器
为每个样式类型创建专属的可视化编辑器：
- **端口样式**：形状选择器、尺寸滑块、颜色选择器
- **节点样式**：背景色选择器、圆角滑块、边框配置
- **控件样式**：输入框样式配置
- **特效样式**：特效类型选择、颜色、时长、强度滑块

### 3. 实时预览优化
- 确保修改参数时预览实时更新
- 添加视觉化的配置操作提示

## 文件修改清单

1. `src/components/tools/StylePresetsLibrary.vue` - 主要重构文件
2. 新增可视化编辑器组件（可选，或直接集成在主组件中）

## 实现步骤

1. 修复 `canSave` 计算逻辑，添加检测配置是否发生变化的功能
2. 添加"复制为自定义样式"按钮和功能
3. 为每种样式类型创建可视化编辑器界面
4. 实现双向数据绑定，确保编辑时预览实时更新
5. 保留 JSON 编辑器作为高级选项
6. 优化 UI 交互体验

## 预期效果

- 用户可以轻松修改样式（通过复制内置样式创建自定义样式）
- 小白用户可以通过直观的表单编辑器配置样式
- 实时预览让用户看到修改效果
- 保存功能正常工作
