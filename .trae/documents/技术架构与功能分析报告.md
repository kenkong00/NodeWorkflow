# 节点编辑工作流平台 - 技术架构与功能分析报告

## 一、项目概述

这是一个**可视化节点编辑工作流平台**，类似于 ComfyUI 的前端界面，支持自定义节点构建、拖拽式工作流编排、实时预览等功能。

**技术栈**：Vue 3 + TypeScript + Pinia + Vue Flow + SQLite (后端) + Vite

---

### 2.2 各功能模块详解

#### **模块1：节点构建器 (NodeBuilderEditor)**

**位置**: [NodeBuilderEditor.vue](src/components/tools/NodeBuilderEditor.vue)

**功能**：
- 可视化创建自定义节点
- 配置节点基本信息（名称、图标、分类）
- 配置输入/输出端口（支持多种数据类型）
- 从控件库拖拽添加控件到节点
- 实时预览节点外观
- 保存/发布节点到数据库

**数据流向**：
```
用户操作 → session(响应式状态) → 预览渲染 → 保存 → nodeService → API → SQLite
```

**关键文件衔接**：
- 使用 [controlLibrary store](src/stores/controlLibrary.ts) 获取可用控件列表
- 使用 [stylePresets store](src/stores/stylePresets.ts) 获取样式预设
- 保存时调用 [nodeService](src/services/nodeService.ts) 写入数据库

**基础架构**：所有控件继承自 [BaseControl.vue](src/components/controls/BaseControl.vue)，提供统一的标签、错误提示、禁用状态等基础功能。

2. **端口样式 (Port Style)**：形状（圆形/方形/菱形）、大小、边框宽度
3. **控件样式 (Control Style)**：背景色、边框色、聚焦色、文字色、字号

#### **模块4：工作区画布 (Workspace Canvas)**

**功能**：
- 基于 Vue Flow 的无限画布
- 支持节点拖拽添加（从左侧节点库）

**位置**: [CustomNodeRenderer.vue](src/components/nodes/CustomNodeRenderer.vue)

- 从节点数据中动态解析控件类型并实例化对应控件

**数据来源**：从拖放事件或数据库加载的节点定义数据

## 三、核心功能流转过程

### 3.1 创建自定义节点的完整流程

```
1. 用户打开「工具 → 节点构建器」
   ↓
2. NodeBuilderEditor 初始化，加载：
   - controlLibrary.loadControls()  // 可用控件列表
   - stylePresets.loadPresets()     // 样式预设
   - nodeStore.loadNodes()          // 已有节点（用于编辑时）
   ↓
3. 用户配置节点属性：
   - 填写名称、选择图标、分类
   - 选择节点样式/控件样式/端口样式
   - 添加输入/输出端口
   - 从右侧控件库拖拽控件到预览区
   ↓
4. 实时预览更新：
   - session 对象（响应式）驱动预览渲染
   - 预览区使用独立的内联样式（非组件复用）
   ↓
5. 点击「保存」：
   - 收集 session 数据
   - 调用 nodeService.create(nodeData)
   - POST /api/nodes → SQLite 存储
   ↓
6. 节点出现在「自定义节点」库中
```

### 3.2 将自定义节点拖入工作台的流程

```
1. 用户在 CustomNodeLibrary 中看到已保存的节点列表
   ↓
2. 拖拽节点项触发 onDragStart：
   - 打包节点数据：type, name, icon, isCustom, customId, controls, inputs, outputs
   - 设置到 dataTransfer: 'application/node-type'
   ↓
3. 拖放到 CanvasView 触发 onDrop：
   - 解析节点数据
   - 判断 isCustom = true
   - 创建新节点对象：
     {
       id: '#xxx',
       type: 'custom',  // 固定为 'custom' 类型
       position: {x, y},
       data: {
         label, icon, isCustom, customNodeId,
         controls, inputs, outputs  // 从拖拽数据传入
       }
     }
   ↓
4. Vue Flow 根据 type='custom' 渲染 CustomNodeRenderer 组件
   ↓
5. CustomNodeRenderer 接收 data props：
   - 解析 inputs → inputPorts 计算属性
   - 解析 outputs → outputPorts 计算属性
   - 解析 controls → sortedControls 计算属性
   - 为每个控件查找对应的控件组件并渲染
   - 为每个带端口的控件创建 PortHandle
   ↓
6. 节点显示在工作台上
```

### 3.3 工作流执行流程

```
1. 用户点击「执行」按钮
   ↓
2. CanvasView.executeWorkflow():
   - 遍历所有边（连接关系）
   - 按拓扑顺序传播数据
   - 对每种目标节点类型做特殊处理：
     * numberInput: 更新数值
     * calculator: 执行计算
     * display: 显示结果
     * textInput/textDisplay: 更新文本
     * loadImage/displayImage: 传递图片
     * singleImageGenerate: 触发AI图像生成
   ↓
3. 结果通过 updateNodeDataById 更新节点数据显示
```

## 四、⚠️ 已知问题：构建器预览与工作台显示不一致

这是你提到的核心问题。经过代码分析，我发现了以下具体的不一致点：

### 4.1 问题根源分析

#### **问题1：端口名称未显示**

**构建器预览** ([NodeBuilderEditor.vue:210](src/components/tools/NodeBuilderEditor.vue#L210)):
```vue
<span class="preview-port-name">{{ port.name }}</span>  <!-- ✅ 显示端口名 -->
```

**工作台渲染** ([PortHandle.vue:13](src/components/nodes/PortHandle.vue#L13)):
```vue
<div v-if="showLabel" class="port-label">{{ label }}</div>  <!-- ❌ 默认 showLabel=false -->
```

**调用处** ([BaseNode.vue:23](src/components/nodes/BaseNode.vue#L23)):
```vue
:show-label="false"  <!-- ❌ 硬编码为 false -->
```

**结果**：工作台中的端口默认不显示名称，而构建器预览中显示。

---

#### **问题2：控件表现不一致**

**构建器预览** ([NodeBuilderEditor.vue:241](src/components/tools/NodeBuilderEditor.vue#L241)):
```vue
<component
  :is="getControlComponent(ctrl.controlType)"
  :model-value="getControlValue(idx)"
  size="small"                    <!-- ✅ 强制 small 尺寸 -->
  :disabled="previewMode === 'view'"
/>
```

**工作台渲染** ([CustomNodeRenderer.vue:36](src/components/nodes/CustomNodeRenderer.vue#L36)):
```vue
<component
  :is="getControlComponent(ctrl)"
  v-model="controlValues[ctrl.id || idx]"
  :label="ctrl.label"
  :placeholder="getControlPlaceholder(ctrl)"
  :show-label="ctrl.showLabel ?? false"   <!-- ⚠️ 来自数据，可能为 false -->
  size="small"                            <!-- ✅ 也是 small -->
/>
```

**差异点**：
- 构建器中使用示例值 (`getControlValue`)
- 工作台中使用实际绑定值 (`v-model`)
- `showLabel` 在工作台中依赖节点数据，可能未正确设置

---

#### **问题3：排版布局差异**

**构建器预览布局** ([NodeBuilderEditor.vue:189-264](src/components/tools/NodeBuilderEditor.vue#L189-L264)):
```
┌─────────────────────────────────────┐
│ Header (图标 + 标题)                 │
├──────────┬──────────────────────────┤
│ 输入端口  │                          │
│ (左侧)    │    控件区域              │
│           │    (每个控件一行)        │
│           │                          │
│           ├──────────────────────────┤
│           │ 输出端口 (右侧)          │
└──────────┴──────────────────────────┘
```

**工作台布局** ([BaseNode.vue + CustomNodeRenderer.vue](src/components/nodes/BaseNode.vue)):
```
┌─────────────────────────────────────┐
│ Header (标题 + ID + 状态)           │
│ [输出端口Handle]  [输入端口Handle]  │  ← 端口在头部下方绝对定位
├─────────────────────────────────────┤
│ 控件1                               │
│ [端口] [标签] [控件本体]            │  ← 每个控件单独一行
│                                     │
│ 控件2                               │
│ [端口] [标签] [控件本体]            │
└─────────────────────────────────────┘
```

**关键差异**：
1. **端口位置不同**：构建器中端口在主体两侧；工作台中端口在头部下方绝对定位
2. **输入输出端口分离**：构建器将所有输入端口集中在一侧，输出在另一侧；工作台将端口分散到各个控件旁边
3. **尺寸不同**：构建器预览固定 420px 宽度；工作台节点宽度来自 `data.initialWidth` 或默认值

---

#### **问题4：样式应用方式不同**

**构建器预览**：通过 JavaScript 函数计算内联样式
```typescript
function getPreviewNodeStyle(): Record<string, string> {
  const nodePreset = styleStore.presets.find(p => p.id === session.selectedStyleIds.nodeStyleId)
  return {
    backgroundColor: config.bg?.primary || '#1a1a1e',
    border: `${config.border?.width || 1}px solid ${config.border?.color || '#3a3a3e}`,
    borderRadius: `${config.radius || 12}px`,
    // ...
  }
}
```

**工作台渲染**：通过 props 传递样式配置对象
```typescript
const nodeStyleConfig = computed<NodeStyleConfig | null>(() => {
  const styleId = props.data?.styleRefs?.nodeId  // ⚠️ 需要从数据中获取
  if (!styleId) return null
  return styleStore.getNodeStyleConfig(styleId)
})
```

**问题**：拖放时 `styleRefs` 可能未正确传递！

查看 [CanvasView.vue:788-794](src/components/canvas/CanvasView.vue#L788-L794)：
```typescript
...(isCustomNode ? {
  icon: nodeType.icon || '',
  isCustom: true,
  customNodeId: nodeType.customId || null,
  controls: nodeType.controls || [],
  inputs: nodeType.inputs || [],
  outputs: nodeType.outputs || []
  // ❌ 缺少 styleRefs！
} : ...)
```

### 6.3 🟡 一般优化建议

- **数据校验**：导入工作流时严格校验数据格式
- **冲突检测**：多人协作时的冲突处理（如果需要）

#### 4. **架构优化**

- **组件解耦**：将样式计算逻辑抽取为 composable
