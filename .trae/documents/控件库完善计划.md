# 控件库完善计划

## 需求分析

用户希望完善控件库功能，实现以下核心功能：
1. 用户可以自定义控件（复制现有控件样式）
2. 控件右侧有样式选择（从样式库中选择预设样式）
3. 可输入数值控件左边有输入端口（如图2所示）
4. 用户可以设置端口的样式
5. 组合好的控件可以保存、删除、修改
6. 自定义控件出现在节点构建器的控件库中供使用

## 当前状态分析

### 现有实现
- **控件库** (`ControlLibrary.vue`): 三栏布局（左侧列表、中间预览、右侧编辑器）
- **样式库** (`StylePresetsLibrary.vue`): 完整的样式管理系统，支持端口/节点/控件/特效样式
- **节点构建器** (`NodeBuilderEditor.vue`): 支持控件拖拽、端口配置、样式选择
- **数据库**: `control_library` 表存储系统控件，`custom_nodes` 表存储自定义节点

### 需要改进的地方
1. 控件库缺少自定义控件创建功能
2. 控件库右侧没有样式选择器
3. 控件没有端口配置功能
4. 自定义控件无法保存到数据库并在节点构建器中使用

## 实施方案

### 阶段 1: 扩展控件类型定义

**文件**: `src/types/control.types.ts`

添加端口配置到控件定义：
```typescript
export interface ControlPortConfig {
  hasInputPort: boolean      // 是否有输入端口
  inputPortDataType?: string // 输入端口数据类型
  inputPortStyleId?: string  // 输入端口样式ID
}

export interface ControlDefinition {
  // ... 现有字段
  portConfig?: ControlPortConfig  // 新增端口配置
  styleRefs?: {                   // 新增样式引用
    controlId?: string            // 控件样式ID
    portStyleId?: string          // 端口样式ID
  }
}
```

### 阶段 2: 增强控件库UI - 添加样式选择器

**文件**: `src/components/tools/ControlLibrary.vue`

修改右侧面板，添加：
1. **样式选择区**: 从样式库加载控件样式预设，提供下拉选择
2. **端口配置区**: 为可输入控件添加端口开关和样式选择
3. **保存/删除按钮**: 自定义控件的保存和删除功能

布局调整：
```
右侧面板结构：
├── 基本信息编辑
├── 控件样式选择 (新增)
│   └── 下拉选择器，加载样式库中的control类别样式
├── 端口配置 (新增)
│   ├── 启用输入端口 [开关]
│   ├── 端口数据类型 [下拉]
│   └── 端口样式选择 [下拉]
├── 配置参数 (现有)
└── 操作按钮 (新增)
    ├── 保存控件
    ├── 复制为新控件
    └── 删除控件 (仅自定义)
```

### 阶段 3: 实现自定义控件CRUD功能

**文件**: 
- `server/repositories/ControlLibraryRepo.ts` - 已有完整CRUD
- `src/services/controlLibraryService.ts` - 已有完整CRUD
- `src/stores/controlLibrary.ts` - 已有完整CRUD

需要修改：
1. 添加"复制控件"功能，基于现有控件创建新控件
2. 保存时包含样式引用和端口配置
3. 删除时只允许删除非系统控件

### 阶段 4: 控件预览带端口

**文件**: `src/components/tools/ControlLibrary.vue`

修改中间预览区域：
- 如果控件启用了输入端口，在预览时左侧显示端口
- 端口样式应用选择的端口样式预设

预览布局：
```
┌─────────────────────────┐
│ ○ 输入端口    控件预览   │
│                         │
│              [输入框]    │
│              [按钮]      │
└─────────────────────────┘
```

### 阶段 5: 集成到节点构建器

**文件**: `src/components/tools/NodeBuilderEditor.vue`

修改控件库加载逻辑：
1. 加载系统控件 + 用户自定义控件
2. 自定义控件显示特殊标记
3. 拖拽到节点时保留端口配置和样式引用

### 阶段 6: 数据库支持

当前 `control_library` 表已支持：
- `config_schema` - 存储配置
- `default_style` - 存储默认样式

需要扩展字段（或存储在config_schema中）：
- `port_config` - 端口配置JSON
- `style_refs` - 样式引用JSON

方案：将新配置存储在现有的 `config_schema` 或 `default_style` 字段中，避免修改数据库结构。

## 预期效果

1. 用户可以在控件库中选择任意控件
2. 在右侧面板选择控件样式和端口样式
3. 为数值类控件启用输入端口
4. 点击"复制为新控件"创建自定义控件
5. 自定义控件出现在节点构建器的控件库中
6. 拖拽到节点时保留所有配置

## 注意事项

1. 系统控件 (`isSystem=true`) 不允许删除和直接修改，只能复制
2. 自定义控件 (`isSystem=false`) 可以修改和删除
3. 样式选择器从样式库的 `control` 类别加载
4. 端口样式从样式库的 `port` 类别加载
5. 端口配置仅对特定类型的控件有意义（如 number、input）
