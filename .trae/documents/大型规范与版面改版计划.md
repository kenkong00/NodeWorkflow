# 节点编辑工作流 v0.1 - 大型规范与版面改版计划

## 📋 项目现状分析

### 当前技术栈
- **框架**: Vue 3 + TypeScript + Vite
- **UI**: Tailwind CSS + Vue Flow (流程图库)
- **状态管理**: Pinia
- **图标**: Lucide Vue Next

### 当前布局结构
```
┌─────────────────────────────────────────┐
│  TopBar (工具栏)                        │
├─────────────────────────────────────────┤
│  TabBar (标签栏)                        │
├──────┬──────────────────────────────────┤
│Icon  │                                  │
│Side  │      CanvasView                  │
│bar   │     (画布区域)                    │
│      │                                  │
│- 文件│                                  │
│- 节点│                                  │
│-配置 │                                  │
│-编辑 │                                  │
└──────┴──────────────────────────────────┘
```

### 当前问题

**1. 布局问题**
- 功能混杂在侧边栏中，不易扩展
- ComfyUI配置和工作流编辑器与画布区域耦合紧密
- 缺乏清晰的功能分区

**2. 节点规范问题**
- 各节点样式不统一（对比 NumberInputNode、LoadImageNode、ComfyUIConnectionNode）
- 端口样式和位置不一致
- 控件组合方式混乱
- 新建节点时容易产生不规范实现
- 样式与业务逻辑未分离

---

## 🎯 改版目标

### 目标1: 三区域选项卡布局
将页面分为三个独立的功能区域，通过顶部选项卡切换：
1. **工作台** - 工作流运行的主要区域（画布+节点操作）
2. **工具区** - 节点配置中心（节点库管理、工作流API的添加/编辑/保存）
3. **配置中心** - 系统配置（ComfyUI多配置管理、大模型API配置）

### 目标2: 统一节点规范体系
建立完整的节点设计规范，包括：
- 节点基础结构标准
- 端口（输入/输出）统一样式
- 连线规则和视觉规范
- 控件库标准化
- 样式与逻辑分离架构

## 🎨 第二阶段：节点规范体系建设

### 2.1 节点设计规范文档

#### 2.1.1 什么是节点（Node Definition）

**节点**是工作流中的基本处理单元，具有以下特征：

```typescript
interface NodeSpecification {
  // 基础信息
  id: string                    // 唯一标识符
  type: string                  // 节点类型（如 'numberInput', 'loadImage'）
  label: string                 // 显示名称
  category: string              // 分类（输入/输出/计算/转换/AI工具等）
  icon?: string                 // 图标（emoji或图标组件名）

  // 外观规格
  width: number                 // 默认宽度（px），建议值：200-400
  height?: number               // 默认高度（px），可选，自适应
  minWidth: number              // 最小宽度，固定值：160
  minHeight: number             // 最小高度，固定值：80
  maxWidth: number              // 最大宽度，固定值：800
  maxHeight: number             // 最大高度，固定值：600

  // 端口定义
  inputs: PortDefinition[]      // 输入端口数组
  outputs: PortDefinition[]     // 输出端口数组

  // 内部控件
  controls: ControlDefinition[] // 控件定义数组

  // 状态和行为
  status?: NodeStatus           // 运行状态
  resizable: boolean            // 是否可调整大小，默认true
}
```

#### 2.1.2 端口规范（Port Specification）

**输入端口（Input Port）**
- **位置**: 节点左侧垂直居中分布
- **外观**: 圆形，直径8px
- **颜色**: 根据数据类型动态着色
- **交互**: 悬停放大1.2倍，连接后实心

**输出端口（Output Port）**
- **位置**: 节点右侧垂直居中分布
- **外观**: 与输入端口相同
- **方向**: 数据流出方向

**端口数据类型**:

| 类型 | 颜色标识 | 用途 |
|------|---------|------|
| number | #3b82f6 (蓝) | 数值数据 |
| string | #f97316 (橙) | 文本数据 |
| image | #22c55e (绿) | 图片数据 |
| boolean | #ef4444 (红) | 布尔值 |
| any | #a855f7 (紫) | 通用类型 |
| comfyui_connection | #10b981 (青绿) | ComfyUI连接 |
| workflow_api | #f59e0b (黄) | 工作流API |

**端口定义示例**:
```typescript
const inputPorts: PortDefinition[] = [
  { id: 'value', name: '数值', dataType: DataType.Number, direction: 'input' },
  { id: 'image', name: '图片', dataType: DataType.Image, direction: 'input' },
  { id: 'trigger', name: '触发', dataType: DataType.Any, direction: 'input' }
]

const outputPorts: PortDefinition[] = [
  { id: 'result', name: '结果', dataType: DataType.Number, direction: 'output' },
  { id: 'image_out', name: '输出图', dataType: DataType.Image, direction: 'output' }
]
```

#### 2.1.3 连线规范（Edge Specification）

**连线样式规则**:
- **粗细**: 默认2px，悬停时2.5px
- **颜色**: 与源端口数据类型一致
- **曲线**: 贝塞尔曲线（smoothstep）
- **动画**: 正在创建的连线使用虚线动画

**连线类型颜色映射**:
```css
.edge-type-number { stroke: #60a5fa; }    /* 浅蓝 */
.edge-type-string { stroke: #fb923c; }    /* 浅橙 */
.edge-type-image { stroke: #4ade80; }     /* 浅绿 */
.edge-type-boolean { stroke: #f87171; }   /* 浅红 */
.edge-type-any { stroke: #c084fc; }       /* 浅紫 */
```

**连接规则**:
- 同类型端口可以连接
- Any类型可以连接任何类型
- 一个输出可以连接多个输入
- 一个输入只能有一个连接（除非明确支持多输入）

#### 2.1.4 控件规范（Control Specification）

**标准控件类型**:

| 控件类型 | 用途 | 适用数据类型 |
|---------|------|------------|
| InputControl | 文本/数值输入 | string, number |
| SelectControl | 下拉选择 | string, enum |
| SliderControl | 滑块调节 | number |
| TextAreaControl | 多行文本 | string |
| ImagePreview | 图片预览显示 | image |
| ButtonControl | 操作按钮 | - |
| SwitchControl | 开关切换 | boolean |
| CheckboxControl | 复选框 | boolean |

**控件统一样式规范**:
```css
/* 控件容器 */
.control-wrapper {
  display: flex;
  flex-direction: column;
  gap: 4px;
  padding: 4px 12px;
}

/* 控件标签 */
.control-label {
  font-size: 11px;
  color: var(--comfy-text-secondary);
  font-weight: 500;
}

/* 控件输入框 */
.control-input {
  width: 100%;
  padding: 6px 10px;
  background: var(--comfy-bg-tertiary);
  border: 1px solid var(--comfy-border);
  border-radius: 6px;
  color: var(--comfy-text);
  font-size: 12px;
  transition: border-color 0.2s;
}

.control-input:focus {
  border-color: var(--comfy-accent);
  outline: none;
  box-shadow: 0 0 0 2px rgba(99, 102, 241, 0.1);
}

.control-input:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
```

#### 2.1.5 节点内部布局规范

**标准节点结构**:
```
┌─────────────────────────────────┐
│ 🔢 节点标题          [状态标签]  │  ← Header (固定)
├─────────────────────────────────┤
│ ○ 输入1  [控件]        ● 输出1  │  ← Body (可变)
│ ○ 输入2  [控件]        ● 输出2  │
│         [控件]                 │
│         [更多控件...]           │
└─────────────────────────────────┘
```

**布局规则**:
1. **Header区域**:
   - 高度: 36px
   - 包含: 图标 + 标题 + ID + 状态标签
   - 背景: 渐变色（从bgTertiary到bgSecondary）
   - 圆角: 顶部12px圆角

2. **Body区域**:
   - 内边距: 上下8px，左右0
   - 控件间距: 4px
   - 端口与控件同行排列（左输入右输出）

3. **端口行布局**:
   ```
   [端口(8px)] [间隔6px] [标签(40px)] [控件(flex-1)] [间隔6px] [端口(8px)]
   ```

### 2.3 节点构建器使用示例

**目标**: 创建一个"图像处理节点"，要求：
- 3个输入端：图片、数值强度、处理模式
- 2个输出端：处理后图片、处理日志
- 控件：图片预览 + 数值输入 + 下拉选择框

**使用nodeBuilder的实现**:

```typescript
// src/nodes/ImageProcessorNode.ts
import { buildNodeSpec } from '@/utils/nodeBuilder'
import { DataType } from '@/types/node'

export const imageProcessorNode = buildNodeSpec({
  type: 'imageProcessor',
  label: '图像处理器',
  category: 'AI工具',
  icon: '🖼️',
  
  dimensions: {
    width: 280,
    minHeight: 200
  },

  inputs: [
    { id: 'input_image', name: '输入图片', dataType: DataType.Image },
    { id: 'strength', name: '强度', dataType: DataType.Number },
    { id: 'mode', name: '模式', dataType: DataType.String }
  ],

  outputs: [
    { id: 'output_image', name: '输出图片', dataType: DataType.Image },
    { id: 'log', name: '日志', dataType: DataType.String }
  ],

  controls: [
    {
      type: 'ImagePreview',
      bindTo: 'input_image',
      label: '源图片',
      position: 'full'  // 占满整行
    },
    {
      type: 'InputControl',
      bindTo: 'strength',
      label: '处理强度',
      inputType: 'number',
      defaultValue: 0.5,
      min: 0,
      max: 1,
      step: 0.1,
      portPosition: 'left'  // 左侧带端口
    },
    {
      type: 'SelectControl',
      bindTo: 'mode',
      label: '处理模式',
      options: [
        { label: '模糊', value: 'blur' },
        { label: '锐化', value: 'sharpen' },
        { label: '边缘检测', value: 'edge' }
      ],
      portPosition: 'left'
    }
  ]
})
```

生成的节点会自动拥有：
✅ 符合规范的尺寸和样式  
✅ 正确位置的输入输出端口  
✅ 统一的控件样式  
✅ 响应式布局  
✅ 可选的调整大小功能
